## City Weather & Country Dashboard

A single-page browser application that lets users search any city worldwide to view live weather conditions, a 3-day midday forecast, and key national profile details (flag, capital, population, and languages). Built using the OpenWeatherMap API, a public REST Countries endpoint, and vanilla HTML, CSS, and JavaScript.
